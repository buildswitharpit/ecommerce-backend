Ecommerce Backend Project - Refactoring and Frontend Implementation

Please perform the following changes to the existing Ecommerce Backend project while following modern development best practices, maintaining clean architecture, and ensuring the application remains fully functional.

Objective

Refactor the existing project into a well-structured monorepo containing separate backend and frontend applications, add Docker support, provide reusable dummy data, and create comprehensive documentation.

1. Backend Project Restructuring

Refactor the existing project structure by moving all backend-related source code into a dedicated backend directory at the root of the repository.

Target Folder Structure
Ecommerce-backend/
├── backend/
├── frontend/
├── dummy-data/
├── docker-compose.yml
├── README.md

Requirements
Move all backend source code into the backend directory.
Update all relative imports and file paths.
Update package scripts.
Update environment variable references.
Update Docker configuration.
Update build configurations.
Update any CI/CD configuration if required.
Ensure the backend functionality remains unchanged after the refactor.
Ensure all existing APIs continue to work without breaking changes.
